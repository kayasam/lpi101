# TP 01 — Découvrir son terminal — Corrigév2

**A1.** Affiche ton répertoire courant.

> [!success]- Afficher la correction — A1
> ```bash
> pwd
> ```
> Le chemin dépend du dossier où ton terminal est ouvert.

**A2.** Affiche le texte `Bonjour le terminal` en conservant les espaces.

> [!success]- Afficher la correction — A2
> ```bash
> echo "Bonjour le terminal"
> ```
> Les guillemets conservent le texte dans un argument.
