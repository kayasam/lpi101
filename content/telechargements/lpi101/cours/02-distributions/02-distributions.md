# 02. Choisir et reconnaître une distribution Linux

> [!note] Objectif
> Repérer les grandes familles de distributions et leurs usages.

---

## Introduction

Le **noyau Linux** est le cœur du système, mais il n’est pas suffisant seul.
Une **distribution Linux** rassemble le noyau, les outils GNU, une interface (graphiques ou non), un système de paquets et divers logiciels.

Chaque distribution est donc une **version complète** du système Linux, adaptée à un public ou un usage particulier.

## Les grandes familles

- **Debian / Ubuntu / Linux Mint** → Simples, stables, très répandues.

- **Red Hat / Fedora / Rocky / AlmaLinux** → Orientation professionnelle, serveurs d’entreprise.

- **SUSE / openSUSE** → Outils d’administration puissants (YaST), souvent utilisés en entreprise.

- **Autres** : Arch (pour experts), Kali (sécurité), Raspberry Pi OS (éducation, embarqué).

---

## Serveur vs Desktop

|Type|Objectif|Interface|Exemple|
|---|---|---|---|
|**Serveur**|Fournir des services (web, mail, base de données)|En général sans interface graphique|Debian Server, Rocky Linux|
|**Desktop**|Utilisation personnelle, bureautique|Interface complète (GNOME, KDE…)|Ubuntu Desktop, Linux Mint|

## À retenir
> [!info]
> - Une **distribution** = noyau Linux + outils + gestionnaire de paquets + interface.
>
> - Les principales familles sont **Debian**, **Red Hat**, et **SUSE**.
>
> - Les distributions peuvent viser un usage **serveur** ou **desktop**.
>
> - **Debian/Ubuntu** sont recommandées pour débuter et pour la formation.
